# Steam 游戏数据分析项目

> **一句话简介**：对 Steam 全量游戏数据（13.9 万条）进行多维度分析，量化「定价、赛道、年度趋势、四象限」四个维度并做统计建模（相关性 / ANOVA / 回归），识别影响游戏商业表现的关键因素，并配套搭建 **FineBI 可视化看板**，为游戏开发与发行决策提供数据依据。

---

## 

## 一、项目背景与目标

- **背景**：Steam 平台游戏数量爆发式增长、竞争加剧（十年增长约 30 倍），开发者面临"如何在海量游戏中突围"的难题。
- **目标**：用数据量化**哪些因素影响游戏的商业表现（销量）与口碑**，从定价、赛道、年度趋势、四象限四个维度切入，并用统计分析验证显著性，给开发者可落地的建议。

---

## 二、数据来源

- **数据集**：Steam Games Dataset（SteamSpy 统计），截至 2026-09-03，共 **139,953** 条游戏，**42** 个字段。
- **字段**：游戏元数据（名称/发布日期/ID）、定价（价格/定价状态）、开发者/发行商、类型（genres/tags/categories）、平台支持、成就、玩家统计（评价数、同时在线、游玩时长）、外部评分（Metacritic）等。
- ⚠️ 原始数据 `steam_games.csv`（约 933MB）**体积过大，未上传 GitHub**，可按需从 Kaggle 下载[Steam Games Dataset](https://www.kaggle.com/datasets/fronkongames/steam-games-dataset)。

## 五、分析流程与核心发现

### 1. 数据清洗与特征工程

- 去除无关字段（42 → 31 列）。
- **修正价格异常**：发现两款游戏标价 107500（实为**越南盾**计价），据此过滤非美元定价（以 `.00` / `.99` 结尾为准）。
- **处理缺失**：`user_score` 99.9% 缺失（0 占位）转 NaN；`metacritic_score` 0 转 NaN；价格空值用中位数填充。
- **衍生字段**：好评率、总评价数、主类型、是否支持中文、平台数、发行年份、销量等级。
- **修复 main_genre**：原数据 22.5% 类型为字典格式（如 `{'id':'1','description':'Action'}`），统一解析为正常类型名。

### 2. 定价敏感度

| 价格区间               | 数量占比 | 口碑（好评率）    | 关键结论                         |
| ---------------------- | -------- | ----------------- | -------------------------------- |
| 免费                   | 20.7%    | 21.9%（最低）     | 下载量大但口碑最差               |
| 低价（<10 美元）       | 60.3%    | ~50%              | 最拥挤，销量低                   |
| **中价（10–30 美元）** | 17.2%    | **56.4%（最高）** | 独立游戏"口碑与商业双赢"理想区间 |
| 高价（>30 美元）       | 1.8%     | 较高              | 销量最高但需强 IP/3A 支撑        |

### 3. 赛道拥挤度

- **红海**：Action（50,039 款，占 **37.2%**）竞争最激烈；Casual、Adventure 长尾效应明显。
- **蓝海**：Simulation（2,758 款，平均销量 **79,375**）、RPG（2,170 款，77,751）、Racing、Utilities——数量少、销量高。
- **口碑**：Animation & Modeling 主流类型中口碑领先（**61.4%**）；Massively Multiplayer 销量最高（115,805）但**口碑最差（28.3%）**。

### 4. 年度趋势

- **数量**：10 年增长超 **30 倍**（约 500 → 17,500 款）。
- **价格**：平均价从约 **8.5 美元**降至 **6.1 美元**。
- **口碑**：平均好评率**先稳后降**（2025 年约 19.8%）。

### 5. 四象限分析（进阶版：仅统计评论数 ≥100 的 11,103 款）

以销量中位数 35,000、好评率中位数 85.7% 为界：

| 象限           | 占比      | 含义                         |
| -------------- | --------- | ---------------------------- |
| **叫座不叫好** | **32.7%** | 高销量低口碑，头部 IP/强营销 |
| 叫好又叫座     | 30.9%     | 品质与商业双赢               |
| 叫好不叫座     | 19.1%     | 有口碑没销量（"遗珠"）       |
| 双输           | 17.3%     | 品质与曝光双缺               |

> 结论：销量与口碑**高度同向**（r≈0.61），但约 1/3 游戏"错位"——商业成功不只靠品质，**营销 / 发行 / 定位**同样关键。

### 6. 统计建模

- **相关性**：与销量相关最强是**好评率（r=0.61）**，其次定价（0.34）、外部评分（0.23）；**发行年份负相关（-0.32）**。
- **ANOVA**：不同价格区间、主类型差异**均显著（p<0.001）**。
- **回归**：销量预测 **R²=0.565**；好评率、价格、支持中文为**正向**，发行年份、免费游戏为**负向**。

## 六、结论与建议

1. **存量竞争**：游戏数量猛增、价格与口碑下滑，平庸产品几乎无生存空间。
2. **定价精准卡位**：独立游戏建议锚定 **10–30 美元**（口碑与利润平衡）。
3. **选对赛道**：商业上优先 **Simulation / RPG**，口碑上关注 **Animation & Modeling**，避开红海。
4. **口碑与营销并重**："高销量低口碑"占近 1/3——**"让好游戏被看见"与"做好游戏"同等重要**。
5. **长期主义**：Steam 老游戏靠时间积累往往获更高评分与持续销量。
